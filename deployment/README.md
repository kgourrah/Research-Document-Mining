
# Research Paper Classification Application

## Project Overview

This application uses a trained machine learning model to classify research paper abstracts into predefined categories.

Users can enter a research abstract and receive a predicted classification.

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- Joblib
- Imbalanced-learn

## Project Files

- app.py: Streamlit application code.
- best_model.joblib: Trained machine learning model.
- requirements.txt: Required Python libraries.

## Installation

Install the required dependencies using:

```bash
pip install -r requirements.txt
```

## Running the Application

Run the following command from the deployment folder:

```bash
streamlit run app.py
```

The application will open in a web browser.

## Using the Application

1. Enter a research paper abstract.
2. Click the Classify Research Paper button.
3. View the predicted research category.

## Machine Learning Model

The application uses the trained model developed and selected during Question 2.
